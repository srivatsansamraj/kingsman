Application Security Engineer
Quillmere Health
Denver, CO (Hybrid, 3 days in office)

About Quillmere Health
Quillmere Health builds scheduling, billing and patient-messaging software used by more than 900 outpatient clinics. Our platform handles protected health information for millions of patients, so security is part of how we build every feature. Learn more at quillmere-health.example.com.

About the role
We are hiring an Application Security Engineer to join our five-person Product Security team. You will work directly with engineering teams across the patient portal, billing and integrations groups to find and fix security problems before they ship. This is a hands-on role: you will spend most of your time reviewing designs and code, testing our APIs, and building tooling that helps developers write secure code by default.

What you'll do
- Lead threat modeling sessions for new features and services, and turn the results into concrete engineering tickets.
- Review pull requests and design documents for injection, authentication, authorization and data exposure flaws.
- Test our REST and GraphQL APIs for broken access control and business-logic issues, and help teams fix what you find.
- Run and tune our static analysis (Semgrep) and dependency scanning in CI, writing custom rules for patterns specific to our codebase.
- Triage findings from scanners, our bug bounty program and penetration tests, assign severity, and track remediation to closure.
- Contribute to secure-by-default libraries and guidance for our Python and Java services.
- Take part in security architecture reviews for changes to our AWS environment.

What we're looking for
- 1 to 3 years of experience in application security, software engineering or a related role; security internships and graduate research count toward this.
- Working knowledge of the OWASP Top 10 and common web and API vulnerability classes.
- Hands-on experience with threat modeling (STRIDE or similar).
- Experience reviewing code for security issues in at least one of Python, Java or Go.
- Familiarity with web testing tools such as Burp Suite.
- Experience triaging vulnerabilities and working with engineers to get them fixed.
- Bachelor's degree in computer science, cybersecurity or a related field, or equivalent experience.

Nice to have
- Experience writing Semgrep or CodeQL rules.
- Exposure to cloud security on AWS (IAM, network controls, logging).
- Experience in a regulated environment such as healthcare (HIPAA) or payments (PCI DSS).
- Relevant certifications such as OSCP or GWAPT.
